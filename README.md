## 의존성 구성

라이브러리 버전은 `egovframe-web-config-parent` 5.1.0(및 `egovframe-rte-root` BOM)이 관리하며, `pom.xml` 에는 parent 가 관리하지 않는 HikariCP·AssertJ 버전만 선언합니다.
WAR 에는 실제로 사용하는 라이브러리만 포함되도록 아래와 같이 정리되어 있습니다.

| 구분 | 내용 |
| :--- | :--- |
| 제외(exclusion) | `egovframe-rte-ptl-reactive` → `spring-webflux` (전이되는 `reactor-core` 도 함께 제외됨, `@EgovNullCheck` 검증 애노테이션만 사용) |
| | `egovframe-rte-psl-dataaccess` → `ibatis-sqlmap` (iBatis 2 미사용, MyBatis 만 사용) |
| | `mysql-connector-j` → `protobuf-java` (X DevAPI 전용) |
| | `commons-logging` (`jcl-over-slf4j`·`spring-jcl` 과 클래스 중복) |
| runtime 스코프 | Log4j2 구현체, log4jdbc, HikariCP, JDBC 드라이버, Hibernate Validator, JSTL 구현체 (설정 파일·JSP 에서만 참조) |
| provided 스코프 | Servlet·JSP API (WAS 제공), Lombok |
| test 스코프 | JUnit Jupiter, Spring Test, AssertJ, Selenium ChromeDriver, Jakarta EL 구현체 |

- 사용하지 않는 DB 드라이버(PostgreSQL 등)는 `pom.xml` 에서 제거해 WAR 크기를 더 줄일 수 있습니다.
- 의존성 점검: `mvn dependency:analyze`, `mvn dependency:tree`
  - `Unused declared` 로 표시되는 JSTL·Log4j2·log4jdbc·HikariCP·JDBC 드라이버·Hibernate Validator 등은 JSP·설정 XML·`@Valid` 에서 런타임에 사용하므로 제거 대상이 아닙니다.
  - `commons-beanutils` 는 `commons-validator` 전이 의존성의 보안 패치 버전 고정용입니다.

## 인증·인가 (Spring Security)

인증·인가는 표준프레임워크 보안 실행환경(`egovframe-rte-fdl-security`)이 구성하는 Spring Security 필터 체인으로 처리합니다.

| 구분 | 내용 |
| :--- | :--- |
| 설정 파일 | `egovProps/conf/egov-security-config.properties` (로그인 URL, 사용자·권한 조회 SQL, CSRF, 동시 세션, 보안 헤더 등) |
| 인증 | 폼 로그인(`/uat/uia/actionLogin.do`) → `DaoAuthenticationProvider` + **BCryptPasswordEncoder** (`hash = bcrypt`) |
| 인가 | DB 롤 매핑(`LETTNROLEINFO`·`LETTNAUTHORROLERELATE`) 기반 URL 권한, 롤 계층 `ROLE_ADMIN > ROLE_USER > ROLE_ANONYMOUS` |
| 로그인 브리지 | `EgovSpringSecurityLoginFilter` 가 화면 파라미터(`id`, `password`, `userSe`)를 Spring Security 파라미터로 변환하고 회원 상태(승인 `P`)를 확인 |
| CSRF | 활성화(`csrf = true`), JSP 폼은 `_csrf` 히든 필드 자동 포함 |

### 게시판 권한 (알림마당 > 공지사항, 자유게시판)

| 기능 | 관리자(`ROLE_ADMIN`) | 사용자(`ROLE_USER`) |
| :--- | :---: | :---: |
| 게시물 등록 | O | X (등록 버튼 미노출) |
| 게시물 수정·삭제 | O (모든 글) | X |
| 답글 등록 | O | O |
| 답글 수정·삭제 | O (모든 답글) | 본인 답글만 |

- 화면 버튼 노출과 요청 처리 모두 `EgovBBSAuthUtil` 기준으로 검증하며, 권한이 없는 요청은 "접근 권한 없음" 화면으로 이동합니다.
- 사용자 화면(`/cop/bbs/*`)에 공통 적용되므로 [게시판생성관리]로 추가한 게시판도 같은 규칙을 따릅니다.

### 비밀번호 체계 (BCrypt)

- 회원 비밀번호, 익명 게시글·QnA 작성 비밀번호는 모두 BCrypt(`$2a$10$...`)로 저장합니다.
- 애플리케이션 코드는 `context-security.xml` 의 `egovPasswordEncoder`(BCryptPasswordEncoder)를 주입받아 `encode()` / `matches()` 로 처리하며, SQL 에서 비밀번호를 직접 비교하지 않습니다.
- `egov-security-config.properties` 의 `hash` 값과 `egovPasswordEncoder` 는 같은 알고리즘이어야 합니다.
- **기존(SHA-256 + ID salt) 데이터 이관** : 기존 해시는 BCrypt 로 변환할 수 없으므로, 초기 비밀번호를 BCrypt 로 재발급(관리자 비밀번호 변경 화면 또는 BCrypt 해시로 `UPDATE`)한 뒤 사용자에게 변경을 안내합니다.

## 데이터베이스

기본 설정은 **HSQL 인메모리 DB**(`Globals.DbType = hsql`, `Globals.Hsql.AutoInit = true`, MySQL 구문 호환 모드)로, 별도 DB 설치 없이 기동 시 스키마와 기초 데이터가 자동 적재됩니다(종료 시 데이터 소멸).
실제 DB를 사용하려면 `DATABASE/` 의 DDL·DML로 스키마와 기초 데이터를 생성한 뒤
`src/main/resources/egovframework/egovProps/globals.properties` 에서 접속 정보를 변경합니다.

```properties
Globals.DbType = mysql            # hsql(기본), mysql, oracle, altibase, tibero, cubrid, postgres, maria, goldilocks
Globals.UserName = pst
Globals.Password = pst01
Globals.DriverClassName = net.sf.log4jdbc.DriverSpy
Globals.Url = jdbc:log4jdbc:mysql://127.0.0.1:3306/pst
```

| DB | DDL·DML | 데이터소스·매퍼 | JDBC 드라이버 |
| :--- | :---: | :---: | :---: |
| HSQL (인메모리, 기본값) | `DATABASE/hsql` | O | 포함 |
| MySQL | O | O | 포함 |
| PostgreSQL | O | O | 포함 |
| Oracle | O | O | 별도 추가 |
| Altibase | O | O | 별도 추가 |
| Tibero | O | O | 별도 추가 |
| Cubrid | O | O | 별도 추가 |
| MariaDB | O | O | 별도 추가 |
| Goldilocks | O | O | 별도 추가 |

- Oracle 등 상용 DB는 해당 JDBC 드라이버 의존성을 `pom.xml` 에 추가해야 합니다.
- MariaDB 매퍼(`*_maria.xml`)는 MySQL 매퍼, Goldilocks 매퍼(`*_goldilocks.xml`)는 Oracle 매퍼를 기반으로 하며, Goldilocks DDL 은 CLOB·BLOB 대신 `LONG VARCHAR`·`LONG VARBINARY` 를 사용합니다.
- MySQL 스크립트는 첫 줄의 `SET NAMES utf8mb4` 로 클라이언트 문자셋을 지정합니다. 이 설정 없이 `latin1` 클라이언트로 적재하면 한글이 깨지고 `COMVNUSERMASTER` 뷰의 collation 충돌로 로그인이 실패합니다.

### 4. Docker / Docker Compose

리소스명(이미지·컨테이너·compose 서비스)은 `egovframe-portal-site-template` 으로 통일되어 있습니다.
Dockerfile 이 멀티 스테이지로 WAR 를 직접 빌드하므로 `mvn package` 없이 실행합니다.

```bash
# 기본 : 내장 HSQLDB (종료 시 데이터 초기화)
docker compose up -d --build

# MySQL 8.4 연동 : 최초 기동 시 DATABASE/mysql 의 DDL·데이터 자동 적재
docker compose -f docker-compose.yml -f docker-compose.mysql.yml up -d --build
```

- 접속: http://localhost:8080/ (ROOT 컨텍스트)
- 이미지 구성: Maven 빌드 → WAR 를 `webapps/ROOT` 로 전개 → `tomcat:10.1-jre17` 에서 **비 root 사용자(UID/GID 1000)** 로 실행, `HEALTHCHECK` 포함
- 이미지만 빌드: `docker build -t egovframe-portal-site-template:5.1.0 .`
- `globals.properties` 의 모든 값은 환경변수로 덮어쓸 수 있습니다. 환경변수명은 키를 대문자로 바꾸고 `.` 을 `_` 로 치환합니다 (예: `Globals.DbType` → `GLOBALS_DBTYPE`). `-DGlobals.DbType=mysql` 같은 JVM 시스템 프로퍼티도 사용할 수 있습니다. 외부 DB 를 쓸 때는 `GLOBALS_HSQL_AUTOINIT=false` 로 HSQL 자동 적재를 끕니다.

| 환경변수 | 대상 / 용도 | 기본값 |
| :--- | :--- | :--- |
| `GLOBALS_DBTYPE` | `Globals.DbType` (`hsql`, `mysql`, `postgres` 등) | `hsql`, `mysql` (mysql 구성) |
| `GLOBALS_URL` | `Globals.Url` (JDBC URL) | `jdbc:log4jdbc:mysql://egovframe-portal-site-template-mysql:3306/pst` (mysql 구성) |
| `GLOBALS_USERNAME`, `GLOBALS_PASSWORD` | `Globals.UserName`, `Globals.Password` | `pst`, `pst01` (`DB_PASSWORD` 로 변경) |
| `GLOBALS_HSQL_AUTOINIT` | `Globals.Hsql.AutoInit` (내장 HSQL 초기화) | `true`, `false` (mysql 구성) |
| `GLOBALS_FILESTOREPATH` | `Globals.fileStorePath` (첨부파일 저장 경로) | `/upload/pst` (볼륨 `upload-data`) |
| `GLOBALS_FILE_ALGORITHMKEY` | `Globals.File.algorithmKey` (첨부파일 ID 암호화 키) | `change-this-file-key` |
| `JAVA_OPTS` | JVM 옵션 | `-Xms256m -Xmx512m -XX:+ExitOnOutOfMemoryError` |
| `MYSQL_ROOT_PASSWORD` | MySQL root 비밀번호 (mysql 구성) | `root1234` |
| `MYSQL_PORT` | MySQL 호스트 노출 포트, `127.0.0.1` 바인딩 (mysql 구성) | `3306` |

- 운영에서는 `.env` 파일 또는 셸 환경변수로 비밀번호·암호화 키를 반드시 변경합니다.
- 초기화: `docker compose -f docker-compose.yml -f docker-compose.mysql.yml down -v` 로 볼륨(DB·첨부파일)을 삭제한 뒤 다시 기동합니다.

### 5. Kubernetes

[k8s/README.md](k8s/README.md) 를 참고합니다. 기본은 내장 HSQLDB 이며, `k8s/mysql/` 을 함께 적용하면 MySQL 로 전환됩니다.

## 테스트

기본 빌드는 테스트를 생략합니다(`pom.xml` 의 `skipTests` 속성). 테스트는 아래와 같이 실행합니다.

```bash
mvn test -DskipTests=false
```

`src/test` 에는 매퍼 SQL 구문·DB별 변형 검증, 검증 메시지 키, BCrypt 로그인·기초 데이터 해시 검증, 유틸리티, 컨트롤러 단위 테스트가 있으며(HSQL 인메모리 사용), Selenium 통합 테스트(`EgovLoginControllerSeleniumIT`)는 failsafe 플러그인으로 `mvn verify -DskipTests=false` 실행 시에만 수행되며, WebDriver가 없으면 자동으로 건너뜁니다.
상단 workflow 배지는 원본 GitHub 저장소 기준이며, 이 디렉터리에는 `.github/workflows` 가 포함되어 있지 않습니다.
